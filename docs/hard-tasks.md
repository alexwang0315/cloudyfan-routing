# #81 試跑題集：跨領域推理難題（`cloudyfan_jev.hard_tasks`）

## 白話說明

舊的 SQL 題太容易，開源模型首答就通過 48–49／50 題，看不出顧問與升級的差別。這批題目跨十個領域、
每個領域五個難度，答案都能由機器判對錯。每題的標準答案由參考解題程式算出，測試再用第二種獨立方法核對。

## 十個題型

| 代號 | 題型 | 參考解 | 測試用的獨立核對 |
|---|---|---|---|
| A | 有障礙與檢查點的格子路徑數 | 分段動態規劃 | 帶狀態的遞迴 |
| B | 有梯子與蛇的棋盤、限定回合內到達終點的機率（第 2 版） | 逐回合位置機率 | 窮舉所有擲骰序列 |
| C | 房屋邏輯謎題（第 2 版：3 級以上六間房、2 級以上無直接位置線索） | 逐項目回溯 | 逐屬性排列求解器確認唯一解（1–3 級）；4–5 級核對答案滿足線索 |
| D | 時間與油料雙重上限、可能要經過指定城鎮的最小成本路徑（第 2 版） | 資源維度動態規劃 | 列舉所有路徑 |
| E | 預測 Python 程式輸出 | 受限命名空間執行 | 手寫同語意的程式 |
| F | 一維細胞自動機多步模擬 | 字串模擬 | 位元運算模擬 |
| G | 五張文字表格的淨營收：匯率、地區變更紀錄、截止日後退款（第 2 版） | 逐列處理 | SQLite 查詢 |
| H | 有限制的字串計數 | 狀態動態規劃 | 窮舉所有字串（最難一級縮短長度後窮舉） |
| I | 多邊形內部滿足餘數條件的格點數（第 2 版） | 射線交叉法逐點判斷 | 繞數法逐點判斷 |
| J | 依規格的 JSON 轉換 | 逐步轉換 | 另一種寫法 |

## 用法

```python
from cloudyfan_jev import hard_tasks
task = hard_tasks.make('E', 4, seed=0)        # 同樣的 (題型, 難度, 種子) 一定得到同一題
env = hard_tasks.HardTaskEnvironment(task)     # 接上 Core 的公開驗收
pool = hard_tasks.candidates(seeds_per_level=2)  # 校準用候選題：10 × 5 × 2 = 100 題
```

- 題目用英文；最後一行要寫 `ANSWER: ...`。驗收器取最後出現的 `ANSWER:` 行，之後多寫字也照收。
- 驗收只回傳 `answer_correct`／`answer_incorrect`／`answer_format_invalid`／`answer_line_missing`，不洩漏標準答案。
- 不提供工具；這批題測不到工具呼叫。
