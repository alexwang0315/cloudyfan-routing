# 首版評分來源使用與人工更新流程

本流程接續已實作的來源匯入、資格包、預覽及快照更新，不新增排程或遠端抓取服務。
本輪只整理既有資料，沒有來源 GET、模型 API、供應商聯絡、部署或正式 current 切換。

## 資料用途與目前缺口

首版使用 CodexRadar 的受控匯入作家族／推理強度的分群參考。
同一來源、同一版本、原生 overall 尺度：低 <80、中 80～100（含邊界）、高 >100。
不能將其他排行榜的分數直接套到這些邊界；value/cost、速度或模型自信也不能冒充 SQL 能力。
開源首答另列，並非低分池的代稱。

已保存的公開資料、三個評分候選各64/64的來源覆蓋及目錄觀察，見
[公開補證](first-pool-public-evidence-20261020.md)；這些不是新的模型答題實測。
榜單沒有提供的 evaluated_at 仍為未知；retrieved_at、latest_graded_at 不取代它。
固定 API 設定是否可用，另依[獨立 SQL 資格](sql-model-qualification-v2.md)。

| 欄位 | 目前可用資料 | 啟用前仍需處理 |
|---|---|---|
| 取得與來源鏈 | 歸檔 URL、時間、原始／正規化 hash、版本、metric、覆蓋已有 | 重新取得時另存新檔與真實時間，不改舊歸檔 |
| 資料使用 | 已保留公開存取觀察與限制 | 來源使用條款、內部使用／商用／再散布適用性未核定；無證據不填同意 |
| 更新責任 | 首版允許人工更新 | 實際人員、更新時限、替代人員與審閱者尚未指定 |
| 模型能力 | 固定版本表、考題與判分工具已有 | 實際 API 身分與完整 SQL 成績尚無，不以榜單補足 |
| 發布資格 | preview／update／inspect 已實作 | 真實 input-bound review 空白、候選 approved=false；不啟用 current |

robots 存取指示不是商用授權；模型 Apache-2.0 也不是排行榜資料授權。
可先從已歸檔條款整理使用範圍；找不到依據時保持待核定，本輪不向供應商詢問。
不必為首版新增 OpenRouter／AA／LiveBench 的整合或改用別家來源湊三池。

## 人工更新責任紀錄

每次更新在受控私有目錄留下以下紀錄；空白代表待指定，不是已核定：

- 來源與條款版本／引用、用途與再散布範圍、確認者及依據。
- 資料取得者、更新負責人、替代人員、審閱者；AI 技術檢查不能冒簽。
- 預定更新時段、時區、下次檢查期限、失敗時負責人。
- 原始來源檔、正規化檔、目錄、資格包、版本及 hash。
- 前後 snapshot／pack ID、preview、operation ID 與操作結果。
- 本次授權範圍；文件或 JSON 文字本身不產生網路、支出或啟用授權。

現行來源與目錄最長48小時、snapshot24小時；SQL資格自其固定規則起算30天。
快照取各證據中最早到期時間。來源過期時停止新任務；不能把下載日期刷新成能力測試日期。
人工更新必須安排在最早到期前；未指定人員或無法維持更新時，首版仍不能持續啟用。
這些期限是現行候選政策，正式營運責任與適用性仍需確認。

## 一次更新的順序

1. **保存目前狀態。** 記錄 current、舊 pack 與進行中任務綁定，不修改它們。
2. **準備新資料。** 本輪只能用既有歸檔或合成資料離線演練；日後獲准讀取公開來源時，保存真實新資料與錯誤，不改舊時間、不把舊檔稱為更新。
3. **檢查來源與版本。** 同一來源／版本／metric／家族／強度；未知欄位照留。版本或設定改變需新包，不能沿用舊 review。
4. **檢查模型資格。** 綁定固定 API 身分、SQL suite／grader／設定 hash、完整成績與有效期間。缺能力、空池、合成冒充真實、費用未知或證據過期都停止。
5. **產生 preview 並審閱。** 核對新增、移除、分群與資格變化；使用方式、人員與 review 未定時保持 blocked。不能依正式比較題答案調整能力卡或門檻。
6. **另有啟用授權且證據齊全才 update。** 使用新 operation ID；同輸入接續可重用原 ID，輸入變更須新 ID。原子 current 只影響新任務。
7. **回讀與封存。** inspect 既有操作紀錄，不重新抓來源、呼叫模型或自動補核定；保留前後包、preview、audit與失敗。

實際 CLI 與原子更新契約見[更新操作](score-update-operations.md)。合成演練使用獨立
runtime store 與 `--synthetic`，不能用此旗標發布真實 current。

## 失敗時怎麼辦

| 狀況 | 人工處理 |
|---|---|
| 來源讀取失敗／取得時間過期 | 保存錯誤，停止新發布；舊 current 到期即停止新任務，不無聲改來源 |
| 家族／強度不明、任一池無合格候選 | 保留排除原因，更新資料或提出明示新版計畫，不降門檻湊池 |
| preview 後 current 被他人更新 | 回讀新 current，重做差異審閱，不強行覆蓋 |
| audit 停在 pending | 原 operation ID 查核／接續；不要用新 ID重複執行同一發布 |
| 資格或費用未核定 | 保留 blocked；來源分數更新不能豁免 RG-02／RG-04 |
| 任務執行中遇到新快照 | 原任務繼續綁原快照與規則，不重送已付費請求 |

現有合成快照更新回歸仍只支持工程行為，不代表真實來源授權、持續時效或正式服務已可用。
