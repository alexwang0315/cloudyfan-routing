## 下一份真實API計畫要交付什麼

本清單**沒有新預算或新模型測試授權**，也不沿用已結束研究的US$10作新額度。付費前先提出：

1. 唯一精確設定數N、實際需新增量測者、可重用證據及不能重用的原因；12位置不等於12份重複資格考試。個別候選能力與整批路由品質門檻分開明列，既有正式資格規則不在此被放寬。
2. 固定資格題數Q、校準數K、最終比較規模H及每階段停點。資格每設定最多兩次作答；若每個設定另有一次身分確認，生成上限為N×(1+2Q)，能用適用首題收據驗身分時按計畫去重，不多發探測。
3. CloudyFan每流程至多3生成／2分類；三組同題最壞共7生成／2分類，即比較階段最多7H生成及2H分類。校準、身分確認及先前中斷另計；不把這個呼叫數公式當價格上限。實際Jev停用則分類為0。
4. 按精確設定與每條可達路徑的有效費率、token／reasoning／cache／失敗／工具邊界計算最壞預留；同時列預估支出、可強制上界、尚未知項與核帳方式。不能用歷史平均單題費乘題數承諾一定完成，也不能用posted零報價豁免費用檢查。
5. 先小批確認身分、保存、核帳與續跑，再按凍結順序進完整量測；未知費用立即停止。小批只驗接線，不先宣告節省或用結果選最好設定。若資格失敗，未執行位置照留，另提新版本，不在原計畫無聲換模型。

免費GET能更新公開或帳戶允許的來源／健康觀測，但不能證明SQL答對率。模型POST能測能力、費用及速度觀察，也不能代替供應商費用保證、來源使用依據或正式資格。所有新增工作仍按實際授權執行；本次沒有讀取憑證或對外呼叫。
